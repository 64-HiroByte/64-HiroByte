## 🚀 Featured Projects

### PressWatch

環境省の報道発表を収集・整理し、環境計量分野のカテゴリやキーワード、公開日で絞り込めるWebアプリケーションです。

前職では、法令・通知・行政情報のキャッチアップが一部の人に依存しやすく、人力での確認では必要な情報を見逃す可能性があると感じていました。

PressWatch は、その課題感をもとに開発しています。

- Repo: [press-watch](https://github.com/64-HiroByte/press-watch)
- Backend: Python / FastAPI
- Database: PostgreSQL
- ORM / Migration: SQLAlchemy / Alembic
- Frontend: Next.js / TypeScript / React
- Theme: 環境 × IT / 業務改善 / 情報収集支援
- 開発状況: 手動での情報取得・保存・分類と、Web画面での一覧表示・絞り込みを実装済み。アプリは未公開で、公開・定期取得に向けたデプロイ先と実行方法を検討中。
